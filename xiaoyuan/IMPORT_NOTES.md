### HLS 低延迟分段播放（2026-11-24）

- 在线视频不再请求整段 6–17 MB 的 MP4，而是请求 4 秒左右的 HLS TS 分段；原始 MP4 在用户本地目录和工作区保留，网站不再发布整段 MP4。
- 60 节视频总时长约 3 小时 30 分，HLS 版本约 300 MiB（以实际输出清单为准），替换原 MP4 可减少约 245 MiB 发布负载。每课分段点播，首段到达即可播放。
- Chrome / Edge 等通过本地 Apache-2.0 hls.js 播放；Safari 使用原生 HLS。无 HLS 支持时显示可读提示，不发起无效的 MP4 请求。
- 分段保持 640×360 H.264 / yuv420p + AAC，便于手机解码；课程句子定位、罗西片尾定位、恢复进度、暂停/续播、倍速、重复、自动下一节和全屏均适用于 HLS。
- 页面当前发布地址为 public GitHub Pages；用户指定的本地视频无账号控制，发布后可由访问网站的人播放。后续如需限制访问，需使用有鉴权能力的视频托管服务。
- HLS 分段已在本地 Chrome 通过 hls.js 实际播放及定位测试。
