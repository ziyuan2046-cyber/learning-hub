## 静态资源与后续维护

- `courses.js`：课程、绘本、来源页码、字幕、中文与音频映射。
- `app.js` / `styles.css` / `index.html`：响应式界面。
- `assets/library/`：本地逐页 WebP 原图；`assets/audio/generated/`：本地独立 MP3。
- `assets/packs/`：线上使用的按文档图片包及按哈希前缀分片语音包；按需读取，避免上千个小文件请求。线上不必再单独上传展开版 WebP / MP3。已验证包内字节与独立文件一致。
- 修改原图或合成文件后，重新运行 `_analysis/import-20261106/pack-assets.py`，更新相应资源包。
- `_analysis/`：OCR 中间产物、校对稿、生成脚本、测试视频、截图、备份和测试报告；**不部署到线上**。
- `sw.js`：只管理本小程序自身缓存，不清理学习空间的其他应用缓存。

## 视频接入边界

- 目前输入文件夹没有视频文件。
- 每个课程和绘本都有「课程视频」入口，支持用户选择本地 MP4 / WebM 等视频并在当前标签页播放。
- 本地视频只保存在内存中，不上传、不公开、不保存平台账号；重新打开标签页需要重新选择。
- 后续可将有权公开使用的直链配置到 `course.video = { src: '...', ... }`。公开嵌入官方播放器时需按平台规则单独实现。
- 不绕过登录、付费、DRM 或加密限制抓取平台视频；购买课程不等同获得公开传播授权。
