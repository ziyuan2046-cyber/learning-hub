## 学习体验

- 默认展示绘本精读目录，切换按钮可以进入自然拼读目录。
- 绘本进入后先打开故事，一页只读一句；再提供关键词、去重重点句子和原页。
- 手机端将英文、中文与朗读按钮放在图片之前，不用先滑过整张图片才能听读。
- 没有图片或图片加载失败时隐藏图片区域；不生成无关的 AI 图片或占位框。
- 单句点读不会自动播放下一页。相同句子在重点句子列表只出现一次；故事原文必要的情节重复保留。
- 20 份 PDF 共 989 页，保留 835 个学习原图页。课程前后宣传、通知等没有做成练习。
- 整理文本有来源页码，原页扫描图中尚未核实的文字不会直接送入朗读。

## 声音说明

已有 394 个新增合成 MP3，保留之前能够匹配的合成录音。

**这里是资料整理与合成英文朗读，不是官方视频课堂，也不冒充教师原声。**

- 每个已整理的句子配有英文、中文及可点击音频。
- 字母名合成朗读不是 /æ/、/b/ 等字母音示范；字母音请结合课件音标学习。
- 歌谣提供合成文字/关键词朗读，不是原课演唱。
- 页面运行不需要语音 API 密钥。MP3 加载失败时尝试设备自带英文朗读，是否可用取决于操作系统。
- 独立 MP3 按需加载，图片使用逐页 WebP，不等待整份课件或声音包下载。

## 没有视频时

视频不是一个学习步骤，不显示空播放器。课程底部仅有默认折叠的“暂未提供，不影响听读”提示。

以后拿到可使用的视频，可以在对应课程选择本机 MP4 / WebM。选择后才创建播放器，文件只留在当前标签页，不上传也不公开，重新打开标签页需要重选。未来可以为有权公开的直链配置 `course.video.src`。

不索取平台账号密码，不绕过登录、付费或加密限制抓取。当前没有官方视频资源，不会伪造“进教室”按钮或无法工作的官方链接。
