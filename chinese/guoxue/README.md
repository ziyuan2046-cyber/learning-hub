# 小学语文国学

依据《统编教材古诗词（文言文）必背包》《拓展诗词包》，并整理三字经、论语、弟子规、千字文等小学国学启蒙内容。国学经典已并入“教材内容”，不再单列来源。

- 教材内容：171 篇（含国学经典 24 篇，三字经、论语、弟子规、千字文各 6 篇）
- 课外拓展：119 篇
- 页面顶部提供全局查询，支持搜索篇名、作者、原文和释义
- 有对应视频的内容可在列表或详情页点击，直接打开哔哩哔哩视频
- 国学篇目提供原文、逐行拼音和朗读，有译文的内容可单独朗读译文
- 历史按最近浏览排序，支持单条删除、清空和撤销
- 筛选面板默认展开，显示当前年级和册次
- “课本必背”采用 2026 年 11 月家长提供的复习资料，覆盖一至六年级上下册，共 208 项（含 7 项选背或待核对）。同一册按资料清单顺序展示；教材版次和学校布置的背诵范围以手头课本为准。
- 可按已背、未背筛选。底部背诵榜只显示本机已背的篇目，按标记时间从新到旧排列，列表有序号，可筛选年级；数据区显示累计已背、本学期已背和本学期未背。本学期未背统计各年级对应册次未标为已背的必背篇目，不含选背（秋季为上册、春季为下册）。站内按本机日期统计：2 月 1 日起为春季，8 月 1 日起为秋季；无日期的旧记录只计入累计数。旧记录沿用已有日期。
- 课本必背显示附件的原文区块，保留整理资料中的背诵范围、正文和分段。译文或例句紧接原文显示，不在学习重点重复输出。
- 考点、字词和默写提醒主要来自附件中的复习笔记，不代表历年真题或考试预测。
- 手机上单列阅读，平板双列篇目，宽屏分栏筛选、并排阅读原文与译注。

双击 `index.html` 可直接阅读。若要使用 PWA、离线音频等能力，可用：

```powershell
python -m http.server 4180
```

再访问 `http://localhost:4180`。
