# 小学语文国学

依据《统编教材古诗词（文言文）必背包》《拓展诗词包》，并整理三字经、论语、弟子规、千字文等小学国学启蒙内容。

- 教材内容：147 篇
- 课外拓展：119 篇
- 国学经典：24 篇，三字经、论语、弟子规、千字文各 6 篇，按年级查询
- 页面顶部提供全局查询，支持搜索篇名、作者、原文和释义
- 有对应视频的内容可在列表直接点开播放器
- 每篇均有原文、逐行拼音和本地朗读；有译文的内容另有译文朗读
- 页面宽度适配手机和平板，正文完整显示

双击 `index.html` 可直接阅读。若要使用 PWA、离线音频等能力，可用：

```powershell
python -m http.server 4180
```

再访问 `http://localhost:4180`。
