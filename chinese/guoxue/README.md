# 小学语文国学

依据《统编教材古诗词（文言文）必背包》《拓展诗词包》，并整理三字经、论语、弟子规、千字文等小学国学启蒙内容。国学经典已并入“教材内容”，不再单列来源。

- 教材内容：171 篇（含国学经典 24 篇，三字经、论语、弟子规、千字文各 6 篇）
- 课外拓展：119 篇
- 页面顶部提供全局查询，支持搜索篇名、作者、原文和释义
- 有对应视频的内容可在列表或详情页点击，直接打开哔哩哔哩视频
- 每篇均有原文、逐行拼音和朗读；有译文的内容可单独朗读译文
- 历史按最近浏览排序，支持单条删除、清空和撤销
- 筛选面板默认展开，显示当前年级和册次
- 290 篇内容均提供白话译文，可单独朗读译文
- 教材内容标注学习重点与常见考查角度，支持筛选重点内容；拓展内容标注理解运用方向
- 页面宽度适配手机和平板，正文完整显示

双击 `index.html` 可直接阅读。若要使用 PWA、离线音频等能力，可用：

```powershell
python -m http.server 4180
```

再访问 `http://localhost:4180`。
