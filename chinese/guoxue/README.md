# 课本国学

人教版小学语文课本国学阅读，按“内容分类 → 年级 → 上册/下册”查询。

## 内容

- 79 篇课内篇目：古诗词、文言文、寓言、神话传说、三字经
- 按教材目录与课文顺序排列
- 原文、逐句拼音、译文、赏析、课文配图
- 每篇配本地 MP3 朗读，可暂停、继续
- 支持篇名、作者、原文搜索，收藏与已读记录
- 手机和平板自适应，最大版心 520px

## 使用

双击 `index.html` 可直接打开。需要完整 PWA 与音频缓存时，在目录中运行：

```powershell
python -m http.server 4180
```

然后访问 `http://localhost:4180`。

## 维护

- `assets/data.js`：分类、筛选与教材数据装配
- `assets/textbook-order.js`：12 册教材目录顺序
- `assets/corrections.js`：逐篇正文校正
- `audio/`：每篇课文的朗读 MP3
- `_tools/bundle-html.cjs`：生成单文件入口

教材篇目依据现行人教版（统编版）小学语文目录整理；朗读音频为本地文件，不依赖第三方视频。
