# 小学古诗文

依据《统编教材古诗词（文言文）必背包》和《拓展诗词包》整理。

- 教材必背：123 篇，按年级、上下册、内容分类查询
- 课外拓展：107 篇，单独标识，不计入教材必背
- 每篇均有原文、逐行拼音、本地 MP3 朗读
- 65 篇教材必背可与官方《不白吃古诗词漫游记》分集明确对应
- 其余篇目提示进入官方合集，不虚构单集对应
- 页面宽度最大 520px，适配手机和平板

双击 `index.html` 可直接阅读。若要使用 PWA、离线音频等能力，可用：

```powershell
python -m http.server 4180
```

再访问 `http://localhost:4180`。
