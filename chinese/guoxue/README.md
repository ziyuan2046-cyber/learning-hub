# 小学语文国学

依据《统编教材古诗词（文言文）必背包》《拓展诗词包》，并结合小学语文课内成语积累整理。

- 教材内容：147 篇，含古诗词、成语、文言文、寓言和神话，按年级、上下册查询
- 课外拓展：119 篇，含古诗词、文言文、寓言和常用成语
- 成语：课内 24 条（每年级 4 条）、课外 12 条，均有释义、例句与朗读
- 每篇均有原文、逐行拼音、本地 MP3 朗读；有译文的篇目另有译文朗读
- 65 篇教材内容可与官方《不白吃古诗词漫游记》分集明确对应
- 其余篇目提示进入官方合集，不虚构单集对应
- 列表完整显示原文，不作两行截断
- 页面宽度最大 520px，适配手机和平板

双击 `index.html` 可直接阅读。若要使用 PWA、离线音频等能力，可用：

```powershell
python -m http.server 4180
```

再访问 `http://localhost:4180`。
