# 小学数学互动小课堂

## 展示方式

数学首页默认打开“互动小课堂”，按年级和上下册各提供一个核心示范实验，共12个。每个实验按“看一看 → 动手试 → 说规律”组织，支持加减按钮、拖动数值、图形变换、播放/暂停、猜答案、答错重试以及重置。

这些实验是教学模型，不代表每册全部知识已经动画化。完整单元、公式、解题方法和自测仍在原来的视图与12个册页中。

| 册次 | 实验 | 观察重点 |
| --- | --- | --- |
| 一上 | 苹果去野餐 | 两部分合起来 |
| 一下 | 十个一捆，减法不难 | 13减几的破十思路 |
| 二上 | 小熊的点心盘 | 几个相同加数与乘法 |
| 二下 | 17颗糖，怎么分 | 分组、商和余数 |
| 三上 | 巧克力分一分 | 平均分、分母与分子 |
| 三下 | 小花园，围还是铺 | 周长与面积的区别 |
| 四上 | 文具店小掌柜 | 单价、数量与总价 |
| 四下 | 果汁怎样分才公平 | 移多补少、总量不变 |
| 五上 | 两个三角形的秘密 | 三角形面积为什么除以2 |
| 五下 | 小方块盖房子 | 一层的个数乘层数 |
| 六上 | 圆，剪一剪就懂了 | 扇形拼接与近似长方形 |
| 六下 | 折扣不是减几元 | 折扣、百分数与现价 |

## 代码与构建

- `assets/lab.js`：12个模型、SVG场景、状态、播放控制和互动题。
- `assets/lab.css`：互动实验界面，兼容减少动态效果偏好。
- `assets/app.js`：选册、视图切换与搜索；切换时清理实验播放和事件监听。
- `assets/data/`：原有课本知识数据。
- `scripts/build-books.js`：重新生成12个静态册页。

在本目录执行：

```sh
node scripts/build-books.js
```

静态部署无需安装依赖。可以用本地HTTP服务预览；实验不依赖第三方脚本或视频服务。
