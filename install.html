没有安装弹窗？按下面操作

  1. 在手机 Chrome 或系统浏览器打开本页。
  2. 点击右上角菜单 ⋮。
  3. 选择 安装应用 / 添加到主屏幕 / 添加到桌面。
  4. 核对图标名称为 学习空间，然后确认添加。

如果菜单没有这些选项，请换用 Chrome 或系统浏览器。按钮点击后没有系统确认框，就不代表安装成功。
